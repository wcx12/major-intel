# plan_history

## 1. 工具原理

`plan_history` 查询学校或学校专业在指定省份、科类、年份下的招生计划历史。它先解析学校和可选专业，再查询招生计划相关表。

## 2. 输入与输出

- 主要输入：`school_text`，可选 `major_text`、省份、科类、年份。
- 关键输出：招生计划记录、计划人数、专业名称、专业组线索。
- 重要说明：招生计划只表示当年计划，不等于录取结果。

## 3. 状态语义

- `ok`：命中招生计划记录。
- `not_found`：没有符合条件的计划记录。
- `needs_clarification`：学校或专业解析需要澄清。
- `partial`：缺少省份、科类或年份时可能返回宽泛样本。
