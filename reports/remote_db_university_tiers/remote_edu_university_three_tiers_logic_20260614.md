## 分类逻辑

按优先级判定：先判第 1 层；未命中再判第 2 层；剩余进入第 3 层。每所学校输出 `university_tier`、`university_tier_name`、`tier_reason` 和 `tier_trigger_codes`。

### 第 1 层：头部/强研究型高校

仅对本科高校判定。命中任一条件即进入第 1 层：

- `is985 = 1`
- `is_dual_class = 1`
- `school_type in (中国研究型, 研究型)`
- `ruanke_rank <= 100`
- `ranking <= 100`

### 第 2 层：区域重点/特色优势高校

未进入第 1 层的学校，命中任一条件即进入第 2 层：

- `is211 = 1`
- `school_type in (特色研究型, 区域研究型, 区域特色研究型)`
- `ruanke_rank <= 350`
- `ranking <= 500`
- `num_doctor/num_doctor2 > 0`
- `num_master/num_master2 > 0`
- `num_academician > 0` / `num_lab > 0` / `key_disciplines > 0` / `is_central = 1`
- 专科/高职：`doublehigh` 非空，或 `features/categories/school_batch/belong` 中出现“双高/高水平高职/国家示范/国家骨干”

### 第 3 层：普通应用/职业供给高校

未命中第 1/第 2 层强信号的高校。
